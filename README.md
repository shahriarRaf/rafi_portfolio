# rafi_portfolio

`rafi_portfolio` is an ASP.NET Web Forms portfolio website project.

## Tech Stack
- ASP.NET Web Forms (.NET Framework 4.7.2)
- C#
- HTML/CSS/JavaScript

## Project Structure
- `Home.aspx` – main homepage
- `WebForm.aspx` – additional page
- `adminlogin.aspx` – admin login page
- `servicesadmin.aspx` – admin services page
- `Site.Master` – shared master layout

## Getting Started
1. Open the project in Visual Studio.
2. Restore NuGet packages if prompted.
3. Run the site using IIS Express.
